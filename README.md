# Todo

Todo is a simple task-list application. The current implementation uses HTML, CSS, and JavaScript and is intended to evolve over time.

## Agent Files

The `agent-files/` directory contains documentation for AI coding agents and is separate from the human-facing README and application source. `AGENTS.md` contains agent instructions, `ARCHITECTURE.md` records finalized architecture, `Agents_Context.md` stores short-term working context, and `CLAUDE.md` provides the Claude entry point.
